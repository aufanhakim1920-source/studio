5 SEPTEMBER 2026 · ONE SESSION

Motion,
measured.

Five short films built in one night, each one gated against fourteen reference reels. The measuring found something I could not see by eye: every video I had ever made without real screen-recording footage was frozen — up to 93% of frames identical to the one before. The footage had been doing the moving. My animation never was.

01

LINE

A PRODUCTION LINE

A belt that never stops, because an object that cannot be still cannot have a frozen frame. It carries real builds from the folder — each colour block's height is that folder's actual size on disk. The zone changes rotate the cards edge-on in 3D while the ground inverts, a technique read off a reference's own peak-motion frame.

02

MORPH

ONE PANEL BECOMING ANOTHER

Commit → stage → build → deploy → check → live, as a single object continuously transforming. The same four files exist in every state and physically travel between layouts. The panel also bends — a real mesh warp, built by slicing the element into 64 columns and offsetting each along a curve, because CSS transforms are affine and physically cannot bend anything.

Paper scrolling under a fixed pen, plotting the night's real measurements: how frozen each of the fourteen reference reels is, against the 45% pass line. The last one shoots off the top at 85%. The trace is the evidence, not a picture of it.

04

QUIET

SILENCE AS MATERIAL

No voice, no music. 48% of it is actual silence. Sound arrives in tight clusters on the moments that move and the holds are left completely empty — which is not the same as spreading a few sounds thinly. Averaged they measure identically; one is a rhythm and the other is a metronome.

05

PULL

A SCREEN-PRINTING SQUEEGEE

Each transition is a blade dragged across the whole frame, laying the next print down and taking the last one with it. Built to reach the motion target by design rather than by repair — the high-energy passage is not an effect applied to the object, it is the object doing its one job.

frozen frames 14.4%four prints, real ink

What the measuring could not do. Twice in one hour a gate rewarded change while the film fell apart — once a departure board that scored beautifully and read “AUFAN HA5EM”, once a fix that slid the words clean off the frame for a perfect score. Every gate here counts changed pixels; none can tell a working film from a disintegrating one. Only looking caught both.

And the mistake I made seven times in one night: confusing amplitude with speed. A “7px float” over 26 frames is 0.27 pixels per frame — invisible. It was area every single time, never count and never speed.
